A picture is worth a thousand records

database.jpg is a real photo. You can open it like any picture. It is also a real database. After the picture data ends, the file holds real microscope images of human cells, real measurements, and embeddings from a pretrained model, each one a list of numbers that describes what a cell looks like.

We use DuckDB, a database engine that can run inside your browser, so you can ask the data real questions with SQL, the language you use to query a database. Then you can watch how we are able to use MorphEm, a pretrained model, to group similar-looking cells together, just by hovering or clicking cells in the plots below.

How this all works

Every piece above runs on the same real data, end to end. Each segmented cell has an embedding, stored in the morphem.features.embedding column as a fixed-size array: 1152 numbers, always in the same order, from the pretrained CaicedoLab/MorphEm model. That fixed length is what lets DuckDB compare any two embeddings directly, using its built-in array_distance function, with no extra setup. This page loads database.jpg into DuckDB-Wasm once, then uses that same function to find the nearest neighbors of the cell you search for or click. The whole page runs in your browser. It does not need a server or Python.

The two plots use that same embedding, drawn two different ways. Each point in the UMAP projection is one real cell. UMAP (McInnes, Healy & Melville, 2018) projects each cell's embedding down to two dimensions, using the reference umap-learn implementation. It measures distance the same way array_distance does above.

Each point in the HNSW graph layout is the same cell, placed by a different method. First, an HNSW index (Malkov & Yashunin, 2016) finds each cell's 6 nearest neighbors. This builds a graph: a network of cells connected to their neighbors. A force-directed layout (from the networkx library) then arranges the graph so that connected cells sit close together. The lines you see are real neighbor connections, not a copy of the UMAP layout.

Does this match the source paper?

That clustering connects to something outside this page: the real study this data came from. Jason Moffat, a co-author of the study that first used this data (Moffat et al. 2006, Cell), provided these images. That study screened many genes and used PH3 staining to measure "mitotic index": the fraction of cells caught in the act of dividing.

This warehouse finds 20 real PH3-positive (mitotic) cells out of 274 in this one field. No one told the model which cells were mitotic. Still, those cells cluster tightly together in both plots above. On average, 86% of a PH3-positive cell's nearest neighbors, found by the HNSW index, are also PH3-positive. Random scattering of mitotic cells predicts only 7%.

MorphEm never trained on this screen. It still recovers the same mitotic-versus-resting distinction the original study measured, using only image shape and texture. That study's actual gene-by-gene results compared many treated wells against controls, and this single, untreated field cannot recover those results. But the clustering above is a real, checkable link to where this data came from.

  • Moffat, J., Grueneberg, D.A., Yang, X., et al. (2006). A lentiviral RNAi library for human and mouse genes applied to an arrayed viral high-content screen. Cell, 124(6), 1283 to 1298. Source of the microscope images and the mitotic-index screen used above.
  • Carpenter, A.E., Jones, T.R., Lamprecht, M.R., et al. (2006). CellProfiler: image analysis software for identifying and quantifying cell phenotypes. Genome Biology, 7(10), R100.
  • Munoz, A.F., Treis, T., Kalinin, A.A., Dasgupta, S., Theis, F., Carpenter, A.E., & Singh, S. (2025). cp_measure: API-first feature extraction for image-based profiling workflows. arXiv:2507.01163. Used to measure the real CellProfiler-equivalent features in this database.
  • CytoTable (cytomining project). Source of the ExampleHuman test fixtures and the join this database's single_cell view follows.
  • Chen, Z., Pham, C., Wang, S., Doron, M., Moshkov, N., Plummer, B.A., & Caicedo, J.C. (2023). CHAMMI: A benchmark for channel-adaptive models in microscopy imaging. NeurIPS Datasets and Benchmarks Track. The dataset MorphEm trained on.
